# Data Directory

This directory contains the raw, processed, and metadata files used by Gene Expression Explorer.

The project uses the publicly available gene expression dataset GSE24177 from the NCBI Gene Expression Omnibus (GEO).

## Data Source

- Organism: Arabidopsis thaliana
- GEO Accession: GSE24177
- Platform Accession: GPL10948
- Repository: NCBI Gene Expression Omnibus

Dataset:
https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE24177

Platform annotation:
https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GPL10948

## Directory Structure

```text
data/
├── raw/
│   ├── GSE24177_series_matrix.txt.gz
│   └── GPL10948_family.soft.gz
│
├── processed/
│   └── GSE24177_expression.csv
│
└── metadata/
    └── sample_metadata.csv
```

## Raw Data

The `raw/` directory contains the original compressed GEO files:

- `GSE24177_series_matrix.txt.gz`: Gene expression measurements and sample information.
- `GPL10948_family.soft.gz`: Platform annotation containing probe and gene information.

These files are used as the source for the downstream analysis workflow.

## Processed Data

The `processed/` directory contains:

- `GSE24177_expression.csv`: A structured expression matrix generated from the GEO series matrix.

Rows represent probe identifiers, while columns represent GEO sample identifiers.

The expression values are used for exploratory analysis and differential expression analysis.

## Sample Metadata

The `metadata/` directory contains:

- `sample_metadata.csv`: Sample identifiers, experimental conditions, time points, biological replicate numbers, and control information.

The dataset includes the following experimental groups:

| Condition | Time Point | Number of Samples |
|---|---|---:|
| Control | Day 1 | 2 |
| Moderate drought | Day 1 | 2 |
| Control | Day 10 | 2 |
| Moderate drought | Day 10 | 2 |
| Control | Wilting | 2 |
| Progressive drought | Wilting | 2 |

## Data Processing

The expression matrix is generated using:

```bash
python src/geo_data_loader.py
```

Dataset consistency and sample metadata are checked using:

```bash
python src/validate_geo_dataset.py
```

The processed expression matrix is subsequently used by the exploratory analysis and differential expression workflows.

## Data Provenance

All original expression data and platform annotations are sourced from the NCBI GEO records referenced above.

The processed files are generated by the project's data preparation scripts.
