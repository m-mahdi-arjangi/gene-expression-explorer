# Data directory

`sample_gene_expression.csv` contains a small **synthetic** teaching dataset adapted from the numeric example used in this project.

- Each row represents a fictional gene.
- Each sample column represents a fictional sample.
- Values are arbitrary expression-like numbers, not measurements from a real experiment.
- There is no clinical information and no disease/control label.

Do not use this file to make biological, diagnostic, or clinical claims. If a public biological dataset is added later, document its accession, source, license, preprocessing steps, and sample metadata here.
